# Global Finance Operations Analytics

## Project Description

This project develops an end-to-end finance analytics solution covering **Order to Cash (OTC)**, **Procure to Pay (PTP)**, and **Record to Report (RTR)** processes.

Using Python, SQL, Excel, and Power BI, the project will clean and validate financial data, calculate key finance KPIs, identify overdue invoices and payment exceptions, analyse vendor performance, and create an interactive dashboard for finance stakeholders.

## Datasets

1. **OTC – Customer Invoices Dataset**
   Used to analyse invoice values, due dates, payment behaviour, overdue invoices, ageing buckets, and late-payment risk.

2. **PTP – Vendor Performance Analysis**
   Used to analyse supplier purchases, vendor performance, payment patterns, spend concentration, and procurement trends.

3. **RTR – General Ledger Financial Dataset**
   Used to analyse account balances, revenue, expenses, debit and credit movements, and financial reporting trends.
